Public release policy

Release only what passes privacy, metadata, and scope review.

HTML, PDF, Markdown, and source code are preferred public formats. Office files and bundled archives remain withheld until they clear privacy, metadata, and publication-scope review.

Current containment

The public Fractalish AI ZIP and public DOCX files have been removed from the current site tree pending scrub and republication review.

Required checks

Release review includes identity scan, local-path scan, metadata review, secret scan, canonical-version review, and deployment reconciliation.

When uncertain

HOLD. No artifact should be promoted as canonical or privacy-safe when the release authority is uncertain.

Office files

DOCX is not a default public format. Office files require comments, tracked-changes, creator metadata, embedded-object, and path review before republication.

Preferred public formats: HTML, PDF, Markdown, and code. HOLD when release authority is uncertain.
