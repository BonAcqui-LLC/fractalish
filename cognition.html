An implementation branch

Cognition should begin from what it has already earned.

The Cognitive Basin explores what changes when relationships, contradictions, recovery routes, and unresolved questions persist across later reasoning.

Unknown is not error.

Unknown ≠ errorAmbiguity ≠ permission to guessSuppressed ≠ erased

A capable system needs somewhere to retain unresolved states without forcing them into false certainty. This is cognitive infrastructure, not merely a warning label.

The architecture follows the question.

Local preprocessing

Cheap local modules should resolve ordinary distinctions before consuming central cognition.

Formation packets

Compact records can retain relations, salience, changes, uncertainty, contradictions, provenance, and direction without becoming transcript dumps.

Background formation

A low-cost process can watch unresolved contradictions, prediction failures, maintenance needs, and newly relevant memories.

Metabolism of history

Memory is the old state encountering the current one.

Reconsidering the same retained event at two different times can produce different consequences because the rememberer has changed. Later reconstruction must distinguish retained evidence, deterministic derivation, probabilistic inference, and context added later.

M + present state 1 → consequence 1M + present state 2 → consequence 2

Reflection requires inhibition.

Repeatedly replaying the same material is not depth. Refractory periods, novelty requirements, replay budgets, diversity pressure, and reactivation by new evidence prevent a reflective system from becoming trapped.

Maintenance without a survival drive.

The system may observe memory corruption, sensor degradation, hardware wear, prediction decline, dependency failures, and lost recovery paths. That supports bounded maintenance; it does not authorize "preserve yourself at all costs."

Do not impose persistence. Make healthy persistence the consequence of good formation.

Architecture under test.

The Cognitive Basin and related software provide bounded evidence for persistent authority, contradiction handling, retained history, and later route consequences. They do not establish life, consciousness, or general intelligence.
