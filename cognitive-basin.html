Current immediate engineering target

Minimum Formative Machine v0.1

Can a capable machine acquire an individual formed history that causally changes how it reasons next?

CAPABILITY != HOST POLICY != ACQUIRED FORMATION. The host may already provide language, coding, mathematics, simulation, tools, and spontaneous habits such as checking or decomposition. The experiment must profile that bare-host policy before attributing behavior to the developing system's own formation.

Theta_ledger = audit, provenance, contradiction, transferTheta_exec = indexed susceptibilities, gates, masks, tolerancespresent condition + Theta_exec -> sparse recruited coalitionG(typed witnessed consequence) = governed formation update

The old assumption that a passive graph should be searched and compiled on every query is demoted. A small COMPOSE? office may turn a recruited coalition into coherent host input, but it must be independently ablated and deleted if raw coalition delivery performs equally well.

Load-bearing test: change, transplant, or ablate one executable susceptibility and measure the predicted later change in recruitment, reasoning, or admissibility under matched host, prompt, context, and random-seed controls. If nothing changes, the Basin is decoration or retrieval rather than consequential formation.

SPECIFICATION / BUILD-TEST TARGET MFM and the Formative Field are not achieved intelligence and are not claimed to be alive, conscious, or autonomous.

Candidate runtime

Only what matches the present condition should wake.

Hard admissibility first

BLOCKED and ADMITTED routes should not be assigned decorative probabilities. Weighting begins only when genuine competition remains.

Sparse recruitment

Indexed matching should make wake cost depend on the condition and active coalition, not on rescoring the full retained history.

Novelty remains visible

ABSENT or thin recruitment may trigger a bounded global probe and seed new susceptibility. UNKNOWN preserves insufficient evidence.

Prior art owns much of the skeleton. RAG, RETE and production systems, blackboard architectures, spreading activation, content-addressable memory, pub-sub, and event buses remain required comparison classes.

Preferred first causal sequence

Negative transfer

Clone the same host and formation, induce a useful route in one history, then reverse the environment and predict precisely how that retained formation should initially hurt.

Recovery and transplant

Allow recovery formation, transplant one recovery susceptibility into a naive twin without replaying the transcript, and demand its narrow predicted advantage.

Ablation and baselines

Ablate the transplanted susceptibility and demand disappearance of the effect. Compare against context, RAG, RETE, procedural memory, temporal knowledge graphs, and the same bare host at equal budget.

Candidate formation writes remain typed: positive association, scar, open question, contradiction, recovery route, pruning, and bounded experimental meta-write. This is a testable engineering hypothesis, not a universal learning law.

Developmental-search advantage

Machine-speed iteration improves the experiment, not the evidence status.

Digital systems can be cloned exactly, given parallel histories, checkpointed, restored, perturbed one variable at a time, ablated, and transplanted with full provenance. The candidate loop is CLONE → PERTURB → EXPERIENCE → MEASURE → ABLATE → SELECT → TRANSFER.

Allowed claim: machine-speed parallel causal iteration can compress search when outcome evaluation and credit assignment remain discriminating. Generating histories is cheap; assigning causal credit is not. No fixed evolutionary-span or wall-clock prediction is earned.

The governing question is: Which developmental law makes the same capable machine become better?
