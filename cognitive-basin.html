Current immediate engineering target

Minimum Formative Machine v0.1

Can a capable machine acquire an individual formed history that causally changes how it reasons next?

CAPABILITY != FORMATION. The host may already provide language, coding, mathematics, simulation, and tool use. The developing system's acquired formation remains a separate, sparse, inspectable state.

Theta = typed formed stateCOMPILE(Theta) = executable reasoning constraintsG(typed witnessed consequence) = governed formation update

A current compiler proposal uses three independently ablatable channels: BRIEF changes what enters consideration; GUARDS changes what may pass without verification; COSTS changes which routes are tried first.

Load-bearing test: change or ablate formation and measure a later change in reasoning path or admissibility under matched host, prompt, context, and random-seed controls. If nothing changes, the Basin is decoration or retrieval rather than consequential formation.

SPECIFICATION / BUILD-TEST TARGET MFM is not an achieved intelligence and is not claimed to be alive, conscious, or autonomous.

First causal experiments

Twin history

Clone the same host and initial formation, give them controlled divergent histories, then present the same held-out challenge.

Single-write transplant

Move one formed object, not a transcript, and test whether its narrow predicted reasoning effect transfers.

Matched baselines

Compare raw context, ordinary RAG, procedural memory, temporal knowledge graphs, and the same host with formation disabled at equal budget.

Candidate formation writes remain typed: positive association, scar, open question, contradiction, recovery route, pruning, and bounded experimental meta-write. This is a testable engineering hypothesis, not a universal learning law.

Developmental-search advantage

Machine-speed iteration improves the experiment, not the evidence status.

Digital systems can be cloned exactly, given parallel histories, checkpointed, restored, perturbed one variable at a time, ablated, and transplanted with full provenance. The candidate loop is CLONE → PERTURB → EXPERIENCE → MEASURE → ABLATE → SELECT → TRANSFER.

Allowed claim: these controls can produce more causally informative developmental iterations per unit time than biological evolution permits. No fixed evolutionary-span or wall-clock prediction is earned.

The governing question is: Which developmental law makes the same capable machine become better?
