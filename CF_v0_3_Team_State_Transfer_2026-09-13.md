# 1. THE CF OPERATION IS NOW EXPLICIT

Earlier CF documents correctly emphasized:

\[
\text{change}\rightarrow\text{retained consequence}\rightarrow\text{altered constraint}\rightarrow\text{altered reachability}.
\]

But the recent boundary round exposed a defect: a reasoner could accept that chain while still taking inherited categories such as *life*, *intelligence*, *self*, *time* or *matter* as primitives.

That is not the operation that produced CF.

The full current sequence is:

\[
\boxed{
\text{SUSPEND}
\rightarrow\text{OBSERVE}
\rightarrow\text{DISTINGUISH}
\rightarrow\text{TRACE CHANGE}
\rightarrow\text{TRACE RETENTION}
\rightarrow\text{MAP CONSTRAINT}
\rightarrow\text{MAP REACHABILITY}
\rightarrow\textbf{AUDIT INDEPENDENCE}
\rightarrow\text{RECONSTRUCT}
\rightarrow\textbf{TYPE THE RETURN}
\rightarrow\text{RENAME ONLY IF EARNED}
}
\]

### Hard Rule 0

> **No inherited category may enter a CF analysis as a primitive merely because the question contains it.**

Words can remain for communication. They cannot do unexplained causal or boundary work.

### Anti-cheat

Removing *life* and replacing it with *organism* is not category suspension.

Removing *mind* and replacing it with *mental process* may not be category suspension.

The observations and relations must survive without the inherited category doing the explanatory work.

### Canonical test

\[
\boxed{
\textbf{A NOUN THAT WAS NEVER REMOVED CANNOT BE SAID TO HAVE SURVIVED.}
}
\]

# 2. THE NOUN MUST EARN ITS WAY BACK — TWICE

The corrected round produced the next correction.

It was not enough to say that a category returned after noun removal. We immediately began turning our own useful returned concepts—*access*, *timescale*, *closure*, *recoverability*—into new primitives.

CF caught itself doing the same thing it was designed to detect.

Every returned concept now faces two tests:

### A. Boundary test

Does observation/intervention force some version of the distinction back?

### B. Independence test

Can the returned concept actually be defined independently of the relations that reconstructed with it?

The current return taxonomy is:

- **PRIMITIVE** — not presently reconstructed from simpler declared relations.
- **OFFICE** — a recognizable functional role instantiated by deeper relations.
- **INDEX** — a coordinate/context needed to evaluate a relation.
- **OPERATOR** — a transformation over states/relations.
- **COMPOSITE / EMERGENT** — stable organization of multiple relations.
- **COMPRESSION NOUN** — useful shorthand for a recurrent conjunction.
- **OPEN DEBT** — unresolved.

A thing may be indispensable without being primitive.

# 3. RESTORE THE GENESIS: TIME / ENERGY / MATTER / GRAVITY

The earlier four-noun round is now a calibration lens for CF itself.

The result was **not**:

> time, energy, matter and gravity are secretly one thing.

Nor was it:

> the four nouns simply disappeared.

Their offices decomposed and repeatedly became difficult to define independently.

Approximate reconstructed offices included:

- **time-like:** ordering, succession, duration, clock relations;
- **energy-like:** conserved quantities under relevant symmetry/rule invariance;
- **matter-like:** persistent constraint-bearing patterns;
- **gravity-like:** persistent structure changing geometry/causal reachability.

Established physics already supplies a mutual-dependency warning of the rough form:

\[
\boxed{
E\leftrightarrow g_{\mu\nu}\leftrightarrow\tau\leftrightarrow\Gamma\leftrightarrow E
}
\]

where \(\Gamma\) denotes causal/reachability structure.

This is not an identity equation. It means one-way noun boxes can misrepresent the dependency structure.

The calibration taught us:

\[
\boxed{
\textbf{WHEN A CONCEPT RETURNS, ASK WHETHER IT CAN STAND ALONE.}
}
\]

Important debts remain: Lorentzian structure, quantum interference, dimensionality/continuity and GR dynamics do not fall out of minimal CF vocabulary for free.

- comparative selection;

\[
\boxed{

# 9. CAPABILITY != FORMATION

This is a major architectural advantage.

A host model may already possess powerful language, reasoning, mathematics, coding, simulation and tool-use capability.

That capability does not have to equal the developing individual's acquired formation.

\[
\boxed{
\textbf{CAPABILITY}\neq\textbf{FORMATION}
}
\]

The host can be treated as a callable reasoning/coding actuator.

The fledgling's formed state decides what has become salient, trusted, scarred, unresolved, associated, recoverable or worth testing.

Thus a developing machine may write Python on its first day while still possessing almost no personal formed history.

We do not have to create intelligence from scratch before studying development.

Create identical starting systems:

\[
A_0=B_0.
\]

Same host capability.

Same initial formation.

Give them different controlled developmental histories:

\[
H_A\neq H_B.
\]

Then expose both to the same held-out challenge.

Test whether:

\[
P(\pi\mid X,\Theta_A)\neq P(\pi\mid X,\Theta_B)
\]

for reasoning path \(\pi\), with random seed, prompt and host controlled.

### SINGLE-WRITE / SUBGRAPH TRANSPLANT

Transfer one formed object from A to B—**not the transcript**—and test whether the narrow predicted reasoning difference transfers with it.

# 13. THE ACCELERATION ADVANTAGE

We are not starting where biological evolution started.

Nature had to discover the physical substrate, replication, sensing, actuation, memory, learning, repair and eventually reasoning machinery.

We already possess capable reasoners and exact digital control.

The more important accelerator is experimental privilege.

We can:

- clone exact states;
- run controlled divergent histories;
- change one operator at a time;
- checkpoint and restore;
- run large populations in parallel;
- inspect every formation write;
- ablate one write;
- transplant one write;
- preserve failed histories;
- run counterfactual branches that biology cannot replay.

Candidate developmental search loop:

\[
\boxed{
