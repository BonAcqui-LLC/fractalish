# Public Release Checklist

- Verify public tree contains no unapproved personal names.
- Verify no local paths or usernames remain in public files or archives.
- Verify `CITATION.cff` uses entity-level attribution.
- Verify office-format files are withheld or sanitized.
- Verify canonical-version registry is current.
- Verify implemented-vs-proposed matrix is current.
- Verify live production matches the approved source tree.
- Verify UTF-8 encoding and no mojibake regressions.
- Verify links, mobile view, and desktop view on key pages.
