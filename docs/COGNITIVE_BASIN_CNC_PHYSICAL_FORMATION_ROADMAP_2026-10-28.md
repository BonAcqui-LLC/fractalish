# Cognitive Basin / CNC physical-formation roadmap

**Status:** WORKING ENGINEERING ROADMAP / NO CONSCIOUSNESS CLAIM

## What remains useful

- **PERCEPT and sensor fabrics:** observation interfaces and declared measurement frames.
- **ATAL / action permits:** bounded intervention authority and fail-closed execution.
- **RIGOR / Authority Compiler / CF-Logic:** evidence qualification, claim typing, and falsifier enforcement.
- **R2R:** cold promotion into binding state after protected evidence and review.
- **Formation Ledger / Basin records:** provenance, lineage, comparison, replay, ablation, and transfer instruments.
- **Natural Math:** deterministic bookkeeping inside its frozen scope.

These are instruments. They do not establish that the named cognitive categories are physically real or independently necessary.

## Categories that must remain experimentally open

Memory, learning, comparison, retrieval, representation, self, intelligence, autonomy, and consciousness may describe useful behavior while failing to identify an independent mechanism. Architecture labels must not be treated as causal proof.

## Gated program

1. **Instrument qualification:** time alignment, calibration, provenance, raw-data retention, failure capture.
2. **Native baseline competition:** state machine, retrieval, learned operator, associative memory, adaptive filter, neuromorphic and material-specific models.
3. **History-dependent response:** matched declared state and matched probe after distinct physical histories.
4. **Causal localization:** ablation, restoration, transplant where physically meaningful, and parameter-blind replication.
5. **Continued reconfiguration:** acquire a new response without destroying previously tested organization.
6. **Additional formative capacity:** demonstrate a held-out capability that was not a stored input-output replay; remove it and show the capability disappears.
7. **Nested coupling:** local intervention with measured local and global consequences; compare against common-driver explanations.
8. **Rupture/recovery:** controlled boundary crossing, post-transition probe, partial loss, cold restart, transfer, and recovery.
9. **Promotion:** only after preregistered gates, independent replay, native baseline comparison, and negative-result preservation.

## Required evaluation matrix

| Test | Required evidence | Failure interpretation |
|---|---|---|
| Continuity without transcript reconstruction | Performance after restart using retained physical/system state while transcript and hidden session state are unavailable | Ordinary replay or host reconstruction remains sufficient |
| History-dependent physical response | Matched probe differs after controlled histories; environment and declared state variables controlled | Missing state variable, drift, damage, or noise remains more likely |
| Continued reconfiguration | New capability plus retained prior capability under the same evaluation contract | Catastrophic replacement or ordinary overwrite |
| Additional formative capacity | Held-out capability; ablation removes it; restoration returns it | Stored lookup, retrieval, or evaluator leakage |
| Nested coupling | Local causal intervention changes declared global response with common-driver controls | Correlation or uncontrolled shared input |
| Bounded rupture | Pre-transition signatures, transition, and post-transition organization measured continuously | Failure observed but mechanism/localization unresolved |
| Cold restart / partial loss / transfer | Predeclared recovery and degradation curves with provenance | Continuity claim unsupported |

## Bounded negative result already in hand

The October `basin_challenge` software harness compared a learned operator, retrieval control, Modern Hopfield regressor, and local consequence structure. All twelve deterministic experiments and the full suite passed, but the main verdict was negative for a distinct runtime mechanism: a known learned operator closed the tested problem. The local candidate's apparent locality depended partly on experimenter-supplied disconnected topology and local entry; composition still required an external constructor. This result narrows the roadmap toward physical, causal, and capacity-acquisition tests.

## Non-claims

This roadmap does not claim machine consciousness, sentience, AGI, unique necessity of physical embodiment, superiority of CNC, completed engineered synapses, or that software modules should be deleted because the orientation changed.
