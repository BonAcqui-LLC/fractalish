# Discussions Guide

If GitHub Discussions is enabled for this repository, these are the suggested categories.

## Suggested Categories

- General questions
- References and prior art
- Morphology examples
- Hostile review
- Dataset leads
- Tooling
- Site and documentation

## How to Use Them

- Use `General questions` for onboarding and orientation.
- Use `References and prior art` for papers, videos, methods, and neighboring work.
- Use `Morphology examples` for images, traces, and comparison cases.
- Use `Hostile review` for skeptical critique, falsification pressure, and boundary testing.
- Use `Dataset leads` for public archives, structured collections, and provenance-rich sources.
- Use `Tooling` for analyzers, descriptors, exports, schemas, and runtime suggestions.
- Use `Site and documentation` for wording, structure, navigation, and release-index fixes.

If Discussions cannot be enabled immediately, use issues with the closest matching template.
