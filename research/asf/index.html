ASF: APTD Sensor Fabric

A provenance-bearing interoperability layer between machine intelligence and observable systems.

  • Core v0.1: public / frozen
  • Motorola M0: public / frozen
  • Read-only observation fabric

Claim boundary: ASF is experimental observational infrastructure. It does not demonstrate a completed physical APTD, machine consciousness, autonomous physical control, production safety, continuous sensing, hardware attestation, or general truth authority.

What ASF is

ASF is an experimental, read-only interoperability fabric for provenance-bearing machine observations. It preserves source, identity, provenance, time, health, sampling semantics, history, and rate limitations before higher layers decide relevance, qualification, formation, or authority.

One interface to observe. No interface to blindly obey.

First physical witness

Motorola Live Probe M0 reports the same semantic proposition, battery = 100%, through five causally distinct sources: a live read-only Motorola observation, a test fixture, a simulation, a replay of the live event, and a text claim. ASF preserves distinct event identities and provenance for those sources.

This matters because the same proposition is not the same causal event. In ASF, that is an executable design property demonstrated by the implementation; it is not promoted here to a universal theorem.

Relation to APTD

ASF is observational infrastructure beneath or alongside the APTD architecture. APTD remains the governed transition/execution boundary. Current ASF stops before physical execution authority.

Relation to Formation Calculus

ASF supplies instrumentation for testing whether retained distinctions such as same semantic proposition with different provenance or acquisition paths later produce different legitimate downstream transitions. ASF does not prove Formation Calculus.

Known limitations

  • Motorola observations are polled snapshots.
  • No claim is made for continuous sensing between polls.
  • SOURCE_BOUND is transport/adapter binding, not cryptographic hardware attestation.
  • The raw device serial is not a public identity.
  • The disconnect test used a host-side invalid binding.
  • No remote feeds are implemented yet.
  • No actuation surface exists in this release.
  • Qualification remains separate and not fully implemented.
  • TEST_FIXTURE was introduced after v0.1 and does not rewrite the Core v0.1 freeze.
