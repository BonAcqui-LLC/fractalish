# Fractalish Public Site v1.2

Static public research site for `https://fractalish.com`.

## Positioning

Fractalish is a public research program of Bonacqui.

Documents are the primary product.

This release presents a calmer, document-first public research home for:

- Fractalish
- Natural Math
- Cognitive Basin
- MCVA / AMCVA / HOLD
- supporting research notes and figures

## Deployment

This package is static and can be deployed directly to Cloudflare Pages.

Suggested settings:

- Build command: none
- Output directory: repository root

If this package is copied into a larger repository, the output directory should be the folder that contains these files.

## Notes

- No analytics or tracking are included.
- No login, comments, or newsletter systems are included.
- Claim posture is intentionally narrow and review-oriented.
