# Fractalish RFCs

This directory holds candidate conceptual, scientific, and governance changes before they become constitutional language.

An RFC should state:

1. the proposed change;
2. the lineage or problem that motivates it;
3. affected projects and definitions;
4. evidence status;
5. claim-boundary effects;
6. unresolved objections or negative evidence;
7. ratification decision, when one exists.

RFCs preserve thinking without pretending every candidate idea has already become law.
