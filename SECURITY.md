# Security Policy

## Public release guardrails

Fractalish public releases should not expose:

- personal names or personal contact details without explicit release approval;
- local file paths, usernames, or workstation metadata;
- bundled archives that have not cleared privacy and scope review;
- unreviewed office-file metadata;
- secrets, tokens, or private service references.

## Reporting

If you notice an exposed local path, metadata leak, unintended identity disclosure, or secret in a public Fractalish release, report it through the repository issue tracker or the public support contact so the artifact can be reviewed and contained.
