# Contributing to Fractalish

Fractalish is a public collaboration hub for morphology work, vocabulary discipline, reference gathering, cautious tooling, and hostile review.

## Contribution Lanes

You can contribute by:

- adding a reference
- submitting a morphology example
- suggesting a dataset
- reporting a site or document issue
- submitting hostile review
- proposing descriptor or tooling improvements
- improving documentation

## What to Include

Every contribution should include:

- source or provenance
- domain
- why it matters
- what claim it supports or challenges
- whether it is best routed as MCVA, AMCVA, or HOLD
- any known limitations

## Good Public Contributions

Strong contributions tend to be:

- traceable
- sourced
- specific
- critical without being vague
- explicit about uncertainty
- clear about what is implemented versus drafted versus speculative

## Guardrails

Do not use this repository to make:

- medical diagnostic claims
- financial advice
- consciousness or personhood claims
- universal-decoder claims
- unsupported causal claims from a single image

## Submission Tips

- If you add a reference, explain what operation or guardrail it informs.
- If you add a morphology example, explain what visible trace matters and what the uncertainty is.
- If you file hostile review, be concrete about what would falsify, weaken, or sharpen the claim.
- If you propose tooling, describe the input, output, and failure mode.

## Pull Requests

Use the pull request template and keep the claim boundary check honest.
