A practical path into the public stack.

If you are new to Fractalish or MCVA, start here.

This project is an open research framework for reading process from form. The narrow question is not whether every branching or cracked structure has one readable cause. The question is when observable morphology preserves enough structure to support comparison, descriptor extraction, and process-memory hypotheses, and when the system should refuse to over-read.

Read in this order:

  1. Whitepaper: the shortest coherent overview of the stack.
  2. MCVA / AMCVA Atlas: the operational lane for readable morphology and guardrails.
  3. Morphological Memory Paper: the thesis layer underneath the tooling.
  4. Project Map: how Natural Math, SERA, HOLD, SymLan, and later lanes fit.
  5. Roadmap: what exists now and what is still future work.

If you want to contribute, the best early help is clarity, stronger non-claims, better manifest structures, public-safe example domains, and simple descriptor or roads-demo work.

The one-sentence rule is: Read form carefully. Preserve uncertainty. Compare before claiming.
